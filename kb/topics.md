# 분류 체계

가이드·안내서·정책자료를 실무 주제별로 묶는 분류다. 가이드 문서 frontmatter 의 `topics` 와 `kb/catalog.md` 가 이 코드를 쓴다. 분류는 찾기 위한 색인일 뿐 법적 구분이 아니다.

코드를 추가·통합할 때는 이 파일을 먼저 고치고 `kb/CHANGELOG.md` 에 한 줄 남긴다. `kb-guide-curator` 는 코드를 새로 만들지 않고 `미분류` 로 보고한다.

우선순위는 요약 초안을 쓰는 순서다(1이 먼저).
