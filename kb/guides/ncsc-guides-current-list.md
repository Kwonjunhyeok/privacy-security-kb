# 국가사이버안보센터 지침·가이드 현행 목록

## 게시 정보

- 출처: 국가정보원 국가사이버안보센터 누리집(https://www.ncsc.go.kr/) 전체메뉴 > 자료실 > 지침·가이드. 2026-11-15 브라우저(Playwright)로 메인 페이지 메뉴 링크를 따라 들어가 1~3쪽 전수 열람. 게시판 표기 "총 23건의 게시물이 있습니다. (1/3페이지)"와 수집 건수(23건) 일치.
- 메뉴 위치: 작업 지시의 "발간자료" 메뉴(자료실 > 발간자료)는 「국가정보보호백서」만 싣는 별도 게시판이다(아래 "발간자료(참고)" 절). 가이드라인·지침(N2SF 보안가이드라인 등)은 같은 자료실의 "지침·가이드" 메뉴에 있다.
- 목록 URL: 모든 메뉴·게시물 주소가 `/ko/main/PageLink.html?token=…` 형태다. 지침·가이드 목록 token 은 위 source_url, 발간자료(백서) token 은 found_at 세 번째 줄. token 이 고정 주소인지(세션·기간에 따라 바뀌는지)는 확인필요. 2026-11-15에는 새 브라우저 세션에서 같은 token 으로 다시 열렸다.
- 쪽 넘김: URL 인자가 없다. 목록 아래 `.paging` 의 쪽 번호·"다음" 링크(href="#")를 눌러 자바스크립트로 목록을 바꾼다. 쪽당 10건. 구분 탭(전체·지침·가이드·기타 공시)도 같은 방식이며 이 목록은 "전체" 탭 기준이다.
- 번호 열은 최신 글이 1번이다(게시판 표기 그대로).
- 게시물 첨부: 링크가 `window['usrBbscttDtl'].downFile('<uuid>',<n>)` 자바스크립트이고 실제 요청은 `https://www.ncsc.go.kr/api/usr/bbs/downloadFile` 이다. 게시물마다 첨부별 SHA-256 해시값을 게시한다. 이번에 받은 3건(N2SF 1.0 본문·부록1, N2SF 이해 및 활용 안내)은 게시된 해시값과 일치했다.
- 담당 부서: 목록·게시물에 담당 부서 칸이 없다(확인필요).
- 현행 표시: "舊 국가 정보보안 기본지침" 한 건에만 기관 표시(舊)가 있다. 나머지는 기관 표시 없음(A 기준): 같은 게시판에 더 새 판이 있으면 "이전 판 제외"로 옮겼다.
- 적용 대상: 이 게시판의 지침·가이드 다수는 국가·공공기관(각급기관)을 대상으로 한다. 민간 기업 실무자가 볼 때는 자료별 적용 대상을 원문에서 확인한다.
- 분류 코드는 `kb/topics.md` 기준. 「병원정보시스템 보안가이드라인(2025.4)」은 맞는 코드가 없어 `미분류`.
- 이번에 원문을 열어 요약 초안을 만든 자료: 「국가 망 보안체계(N2SF) 보안가이드라인 1.0」(kb/_pending/2026-11-15-guides-n2sf-security-guideline.md).
