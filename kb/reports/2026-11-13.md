## 출처 접근 문제
- **접속 확인 결과:** `curl.exe https://www.law.go.kr` 의 응답은 **200** 이다. boho.or.kr, privacy.go.kr, ncsc.go.kr 은 200, pipc.go.kr 과 msit.go.kr 은 경로를 붙이면 200 이다. **isms.kisa.or.kr 은 DNS 해석에 실패**한다(이 PC에서도).
- **law.go.kr**
  - 한글주소 리다이렉트, lsInfoP/lsInfoR, 행정규칙 admRulInfoP 로 조회할 수 있다.
  - 법령명 검색 POST(lsScListR.do)는 Git Bash 에서 한글을 그대로 보내면 0건이 나온다. PowerShell 로 UTF-8 본문을 만들어 보내야 결과가 나온다.
- **pipc.go.kr**
  - 의결서 HTML 미리보기(dscvPreview.do)는 오류가 난다. 의결서는 첨부 다운로드로만 볼 수 있다. 이 때문에 처분 사례 15건이 보류됐다.
  - 보도자료 검색(searchWrd)은 결과가 0건이다.
- **msit.go.kr:** 보도자료 본문이 첨부(hwpx)에만 있다. 목록은 스크립트로 그려진다.
- **ncsc.go.kr:** 게시판이 토큰 링크와 스크립트 렌더링이라 curl 로 목록을 뽑을 수 없다.
- **판단이 필요한 것**
  1. 처분 사례의 두 번째 A 출처 기준. 의결서 파일 다운로드를 허용할지, 아니면 '보도자료 + 결정문 게시판 메타데이터(대상·의결일·의안번호) 일치'를 2곳으로 인정할지 정해야 한다. 정하지 않으면 attempts 2 인 처분 11건이 다음 실행에서 기각된다.
  2. sources.md 에 금융위원회(fsc.go.kr, 신용정보법 소관) 등급을 추가할지
  3. 정보통신망법 시행규칙을 추적 대상에 넣을지
  4. 안내서처럼 pipc.go.kr 에만 게시되는 자료의 2곳 기준
- **ISMS-P 인증 고시의 공백:** 현행본은 2024-07-24 판이다. 정보통신망법 제21500호와 시행령 제36735호가 2026-10-01 부터 강화인증과 서면·현장 심사 병행을 시행하고 있지만, 고시는 아직 이를 반영하지 않았다(법령 검증기 관찰).
