# WordPress 제품 보안 업데이트 권고 (WordPress, CVE-2026-87902, 2026-09-23)

- 게시: KISA 보호나라 보안공지 「WordPress 제품 보안 업데이트 권고」, 2026-09-23 (nttId=72197)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- WordPress 재단은 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- WordPress에서 발생하는 PHP Remote File Inclusion 취약점(CVE-2026-87902) [1][2]
