# Oracle 제품 보안 업데이트 권고 (2026-11-18)

- 게시: KISA 보호나라 보안공지 「Oracle 제품 보안 업데이트 권고」, 2026-11-18 (nttId=72313)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.

## 개요

- Oracle社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Oracle Java SE, Oracle JavaFX의 libxml2에서 발생하는 XML 외부 엔티티(XXE) 주입 및 SSRF 취약점(CVE-2026-86144) [1][2]
- Oracle Java SE의 Compiler에서 발생하는 Heap-based Buffer Overflow 취약점(CVE-2026-114938) [1][3]
- Oracle Java SE의 JGSS에서 발생하는 정보 노출 및 데이터 변조 취약점(CVE-2026-114939) [1][4]
- Oracle Java SE의 JSSE에서 발생하는 정보 노출 및 데이터 변조 취약점(CVE-2026-114940) [1][5]
- Oracle Java SE의 Compiler에서 발생하는 서비스 거부 및 데이터 변조 취약점(CVE-2026-114941) [1][6]
- Oracle Java SE의 Libraries에서 발생하는 서비스 거부 및 데이터 변조 취약점(CVE-2026-114942) [1][7]
