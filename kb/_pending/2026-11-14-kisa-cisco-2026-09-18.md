# Cisco 제품 보안 업데이트 권고 (Cisco ISE·Cisco ISE-PIC 등, CVE 2건, 2026-09-18)

- 게시: KISA 보호나라 보안공지 「Cisco 제품 보안 업데이트 권고」, 2026-09-18 (nttId=72193)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- Cisco社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1][2]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Cisco Identity Services Engine(ISE), Cisco ISE Passive Identity Connector(ISE-PIC)에서 발생하는 Incorrect Use of Privileged APIs 취약점(CVE-2026-76460) [1][3]
- Cisco AsyncOS Software for Cisco Secure Email Gateway에서 발생하는 SQL Injection 취약점(CVE-2026-76461) [2][4]
