# PHP2Shell 및 후속 PHP 취약점

## KISA 「PHP 제품 보안 업데이트 권고」 (2026-10-21, nttId 72227)

- CVE-2026-109618 (Improper Handling of Exceptional Conditions), CVE-2026-109619 (Use After Free)
- 영향/해결 버전: 8.2.35 미만→8.2.35 이상, 8.3.36 미만→8.3.36 이상, 8.4.27 미만→8.4.27 이상, 8.5.12 미만→8.5.12 이상
- PHP 8.1 이하는 공식 지원 종료 → 지원 버전으로 전환. 7.4·8.0·8.1은 벤더별 조치 상이.
- 참고: php.net/archive/2026.php#2026-10-21-5, GHSA-w8hw-w9fx-j79w, GHSA-6wmf-4rv5-p3rp

## KISA 「PHP 보안취약점(PHP2Shell) 관련 기업 보안 대응 수칙」 (2026-10-22, nttId 72230, 공지 고정)

- CVSS 9.2. 로그인 없이 원격 명령 실행. 웹셸 설치·고객정보 유출·홈페이지 변조·내부망 침투 가능. 패치 전 상세정보 유출, 해외 보안업체 중심 공격 시도 보고.
- PHP 8.2 보안 지원 2026.12.31. 종료 예정.
- 네트워크 장비·관리 콘솔·Windows 설치본·컨테이너 이미지 내장 PHP도 점검 대상.
- 조치 요지: 인터넷 노출 PHP 자산 전수 파악(외주·테스트·관리자 사이트 포함) → 업데이트 후 PHP 서비스 재시작/이미지 재배포 → 실제 구동 버전 확인 → 8.1 이하 이전 → 즉시 패치 불가 시 임시완화(요청 크기 제한, 불필요 multipart 업로드 차단, WAF 룰, `session.upload_progress.enabled = 0` 등) → 유출일 이후 로그 점검(대용량 요청 후 HTTP 500, PHP 크래시, 셸 실행, 웹 디렉터리 신규 PHP 파일, 비정상 외부 연결) → 노출 서버 자격증명 교체 → 침해 시 격리·신고·증거 보전 → 출처 불명 PoC 실행 금지.
- 로그 점검 시작일: 페이지 표기 "10.20."로 불완전 → 확인필요

## KISA 「PHP 신규 취약점(CVE-2026-115560) 임시 조치 권고」 (2026-10-24, nttId 72237)

- PHP 세션 처리 과정 원격 코드 실행. CVSS 미표기. 영향 버전 "제조사 미공개".
- 10.21 배포 업데이트(8.5.12/8.4.27/8.3.36/8.2.35)로 해결되지 않음. 패치 "미배포(차기 정기 업데이트 예정)".
- 영향 조건(모두 충족): `session.serialize_handler` 가 php_binary 또는 php_serialize, `session_start()` 전 `ini_set()` 으로 php 로 변경, `session.upload_progress.enabled` 활성(기본값).
- 임시조치: `session.upload_progress.enabled=0` 후 PHP 워커 전체 재시작. PHP2Shell 임시조치 적용 시 추가 조치 불요.
