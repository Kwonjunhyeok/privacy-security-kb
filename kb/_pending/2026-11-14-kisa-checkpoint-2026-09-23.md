# Check Point 제품 보안 업데이트 권고 (Security Management Server·Multi-Domain Security Management Server 등, CVE-2026-93616, 2026-09-23)

- 게시: KISA 보호나라 보안공지 「Check Point 제품 보안 업데이트 권고」, 2026-09-23 (nttId=72198)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- Check Point社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Check Point Security Management Server, Multi-Domain Security Management Server, Log Server, Multi-Domain Log Server, SmartEvent에서 발생하는 Path Traversal 취약점(CVE-2026-93616) [1][2]
