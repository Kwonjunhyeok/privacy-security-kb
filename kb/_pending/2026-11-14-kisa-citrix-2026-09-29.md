# Citrix 제품 보안 업데이트 권고 (NetScaler ADC·NetScaler Gateway 등, CVE 8건, 2026-09-29)

- 게시: KISA 보호나라 보안공지 「Citrix 제품 보안 업데이트 권고」, 2026-09-29 (nttId=72201)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- Citrix社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- NetScaler ADC, NetScaler Gateway에서 발생하는 Improper Input Validation 취약점(CVE-2026-88771) [1][2]
- NetScaler ADC, NetScaler Gateway에서 발생하는 Improper Restriction of Operations within the Bounds of a Memory Buffer 취약점(CVE-2026-88772) [1][3]
- NetScaler ADC, NetScaler Gateway에서 발생하는 HTTP Request/Response Smuggling 취약점(CVE-2026-88773) [1][4]
- NetScaler ADC, NetScaler Gateway에서 발생하는 보안 설정 미흡 취약점(CVE-2026-88774) [1][5]
- NetScaler ADC, NetScaler Gateway에서 발생하는 Classic Buffer Overflow 취약점(CVE-2026-88775) [1][6]
- NetScaler ADC, NetScaler Gateway에서 발생하는 Improper Restriction of Operations within the Bounds of a Memory Buffer 취약점(CVE-2026-88776) [1][7]
- NetScaler ADC, NetScaler Gateway에서 발생하는 Improper Restriction of Operations within the Bounds of a Memory Buffer 취약점(CVE-2026-88777) [1][8]
- NetScaler ADC, NetScaler Gateway에서 발생하는 Predictable Exact Value from Previous Values 취약점(CVE-2026-88778) [1][9]
