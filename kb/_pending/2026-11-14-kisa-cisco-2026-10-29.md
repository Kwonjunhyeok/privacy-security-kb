# Cisco 제품 보안 업데이트 권고 (Expressway Series·Emergency Responder 등, CVE 16건, 2026-10-29)

- 게시: KISA 보호나라 보안공지 「Cisco 제품 보안 업데이트 권고」, 2026-10-29 (nttId=72244)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- Cisco社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[3]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Cisco Expressway에서 발생하는 Use of Hard-coded Credentials 취약점(CVE-2026-76466) [1][4]
- Cisco Expressway에서 발생하는 Out-of-bounds Write 취약점(CVE-2026-76490) [2][5]
- Cisco Expressway에서 발생하는 Reachable Assertion 취약점(CVE-2026-76491) [2][6]
- Cisco Expressway에서 발생하는 NULL Pointer Dereference 취약점(CVE-2026-76492) [2][7]
- Cisco Expressway에서 발생하는 Uncaught Exception 취약점(CVE-2026-76493) [2][8]
- Cisco Expressway에서 발생하는 Code Injection 취약점(CVE-2026-76494) [2][9]
- Cisco Expressway에서 발생하는 Incorrect Permission Assignment for Critical Resource 취약점(CVE-2026-76495) [2][10]
- Cisco Expressway에서 발생하는 Link Following 취약점(CVE-2026-76496) [2][11]
- Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, Unity Connection에서 발생하는 Injection 취약점(CVE-2026-76473) [3][12]
- Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, Unity Connection에서 발생하는 Improper Authentication 취약점(CVE-2026-76474) [3][13]
- Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, Unity Connection에서 발생하는 Cross-site Scripting 취약점(CVE-2026-76475) [3][14]
- Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, Unity Connection에서 발생하는 Improper Input Validation 취약점(CVE-2026-76476) [3][15]
- Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, Unity Connection에서 발생하는 SQL Injection 취약점(CVE-2026-76477) [3][16]
- Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, Unity Connection에서 발생하는 Improper Access Control 취약점(CVE-2026-76478) [3][17]
- Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, Unity Connection에서 발생하는 Path Traversal 취약점(CVE-2026-76479) [3][18]
- Cisco Emergency Responder, Prime Collaboration Deployment, Unified CM, Unified CM IM&P, Unified CM SME, Unity Connection에서 발생하는 Improper Check or Handling of Exceptional Conditions 취약점(CVE-2026-76481) [3][19]
