# Fortinet 제품 보안 업데이트 권고 (2026-11-16)

- 게시: KISA 보호나라 보안공지 「Fortinet 제품 보안 업데이트 권고」, 2026-11-16 (nttId=72308)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.

## 개요

- Fortinet社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[14]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- FortiManager에서 발생하는 Improper Authorization 취약점(CVE-2026-126261) [1][15]
- FortiAnalyzer, FortiManager에서 발생하는 SQL Injection 취약점(CVE-2026-126262) [2][16]
- FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, FortiManager Cloud에서 발생하는 Authentication Bypass by Spoofing 취약점(CVE-2026-126184) [3][17]
- FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, FortiManager Cloud에서 발생하는 Improper Certificate Validation 취약점(CVE-2026-126232) [4][18]
- FortiOS에서 발생하는 Missing Authentication for Critical Function 취약점(CVE-2026-126259) [5][19]
- FortiOS에서 발생하는 Authentication Bypass by Primary Weakness 취약점(CVE-2026-126253) [6][20]
- FortiOS에서 발생하는 Out-of-bounds Read 취약점(CVE-2026-126256) [7][21]
- FortiOS에서 발생하는 Stack-based Buffer Overflow 취약점(CVE-2026-126258) [8][22]
- FortiOS에서 발생하는 Improper Certificate Validation 취약점(CVE-2026-121528) [9][23]
- FortiAnalyzer, FortiAnalyzer Cloud, FortiAnalyzer-BigData, FortiManager, FortiManager Cloud에서 발생하는 Improper Encoding or Escaping of Output 취약점(CVE-2026-126170) [10][24]
- FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, FortiManager Cloud에서 발생하는 XML Injection 취약점(CVE-2026-126176) [11][25]
- FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, FortiManager Cloud에서 발생하는 XML Injection 취약점(CVE-2026-126177) [11][26]
- FortiOS, FortiPAM에서 발생하는 Path Traversal 취약점(CVE-2026-126255) [12][27]
- FortiManager에서 발생하는 Use of Hard-coded Credentials 취약점(CVE-2026-126181) [13][28]
- FortiOS에서 발생하는 Numeric Truncation Error 취약점(CVE-2026-126254) [14][29]
