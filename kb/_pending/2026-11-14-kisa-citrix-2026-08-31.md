# Citrix 제품 보안 업데이트 권고 (NetScaler ADC FIPS·NetScaler ADC NDcPP 등, CVE 5건, 2026-08-31)

- 게시: KISA 보호나라 보안공지 「Citrix 제품 보안 업데이트 권고」, 2026-08-31 (nttId=72173)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- Citrix社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- NetScaler ADC, NetScaler Gateway에서 발생하는 Out-of-bounds Read 취약점(CVE-2026-8451) [1][2]
- NetScaler ADC, NetScaler Gateway에서 발생하는 Improper Restriction of Operations within the Bounds of a Memory Buffer 취약점(CVE-2026-8452) [1][3]
- NetScaler ADC, NetScaler Gateway에서 발생하는 Improper Restriction of Operations within the Bounds of a Memory Buffer 취약점(CVE-2026-8655) [1][4]
- NetScaler ADC, NetScaler Gateway에서 발생하는 External Control of File Name or Path 취약점(CVE-2026-10816) [1][5]
- NetScaler ADC, NetScaler Gateway에서 발생하는 Missing Release of Memory after Effective Lifetime 취약점(CVE-2026-13474) [1][6]
