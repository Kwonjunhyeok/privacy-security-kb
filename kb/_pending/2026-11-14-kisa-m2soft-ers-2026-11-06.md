# 엠투소프트 ERS DataServer·ReportingServer 엔진 보안 업데이트 권고 (2026-11-06)

- 게시: KISA 보호나라 보안공지 「엠투소프트 제품 보안 업데이트 권고」, 2026-11-06 (nttId=72285)
- 아래 표·값은 공지 본문 그대로 옮김.

## 개요

- 엠투소프트社가 자사 제품 취약점을 해결한 보안 업데이트 발표 [1][2]
- 낮은 버전 사용자는 제조사 해결 방안 안내에 따라 조치 권고

## 설명

- ERS DataServer 및 ERS ReportingServer 엔진(JavaViewer)에서 발생하는 악의적인 파일 업로드 및 실행 가능 취약점 [1][2]
- CVE 번호: 공지 본문에 기재 없음

## 영향을 받는 제품

| 제품명 | 영향받는 버전 | 해결 방안 (공지 표기) |
|---|---|---|
| ERS DataServer | 6.4.5.494 이하 | 6.4.5.495 이상 (최신 버전 : 6.4.5.506) |
| ERS DataServer | 7.4.4.684 이하 | 7.4.4.685 이상 (최신 버전 : 7.4.4.707) |
| ERS DataServer | 8.2.2.328 이하 | 8.2.2.329 이상 (최신 버전 : 8.2.2.359) |
| ERS ReportingServer 엔진(JavaViewer) | CROWNIX Report&ERS 6 - Java Engine Version : 5.x 이상 5.5.14.1070 이하 | Java Engine Version : 5.5.14.1071 이상 (최신 버전 : 5.5.14.1108) |
| ERS ReportingServer 엔진(JavaViewer) | CROWNIX Report&ERS 7 - Java Engine Version : 7.x 이상 7.4.3.960 이하 | Java Engine Version : 7.4.3.961 이상 (최신 버전 : 7.4.3.1109) |
| ERS ReportingServer 엔진(JavaViewer) | CROWNIX Report&ERS 8 - Java Engine Version : 8.x 이상 8.2.0.345 이하 | Java Engine Version : 8.2.0.346 이상 (최신 버전 : 8.2.3.664) |

※ 해결 버전은 엠투소프트에 문의 후 설치(공지 표기)

## 조치 방법

1. 해결 버전으로 업데이트
2. 추가 조치
   - ERS DataServer: 디렉토리 경로 변경(`./DataServer/manager` → `./DataServer/WEB-INF/manager`, `./DataServer/formmanager` → `./DataServer/WEB-INF/formmanager`), 최신 라이브러리 파일(ers-data-core.jar 등)을 `./DataServer/WEB-INF/lib` 에 덮어쓰기, `./DataServer/uploadf.jsp` 제거
   - ERS ReportingServer 엔진(JavaViewer): 디렉토리 경로 변경(`./ReportingServer/manager` → `./ReportingServer/WEB-INF/manager`), 최신 라이브러리 파일(javard.jar 등)을 `./ReportingServer/WEB-INF/lib` 에 덮어쓰기
