# Plex 제품 보안 업데이트 권고 (Plex Media Server, CVE 5건, 2026-10-20)

- 게시: KISA 보호나라 보안공지 「Plex 제품 보안 업데이트 권고」, 2026-10-20 (nttId=72223)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- Plex社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Plex Media Server에서 발생하는 Path Traversal 취약점(CVE-2026-96651) [1][2]
- Plex Media Server에서 발생하는 SSRF 취약점(CVE-2026-96652) [1][3]
- Plex Media Server에서 발생하는 Improper Neutralization of Encoded URI Schemes in a Web Page 취약점(CVE-2026-96654) [1][4]
- Plex Media Server에서 발생하는 SSRF 취약점(CVE-2026-96655) [1][5]
- Plex Media Server에서 발생하는 External Control of File Name or Path 취약점(CVE-2026-96656) [1][6]
