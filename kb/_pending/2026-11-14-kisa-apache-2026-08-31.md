# Apache 제품 보안 업데이트 권고 (Apache Tomcat, CVE 10건, 2026-08-31)

- 게시: KISA 보호나라 보안공지 「Apache 제품 보안 업데이트 권고」, 2026-08-31 (nttId=72175)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- Apache 재단은 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[10]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Apache Tomcat에서 발생하는 Improper Authentication 취약점(CVE-2026-68569) [1][11]
- Apache Tomcat에서 발생하는 Incorrect Authorization 취약점(CVE-2026-68525) [2][12]
- Apache Tomcat에서 발생하는 Uncontrolled Resource Consumption 취약점(CVE-2026-66299) [3][13]
- Apache Tomcat에서 발생하는 Improper Access Control 취약점(CVE-2026-65182) [4][14]
- Apache Tomcat에서 발생하는 Time-of-check Time-of-use (TOCTOU) Race Condition 취약점(CVE-2026-65183) [5][15]
- Apache Tomcat에서 발생하는 Uncontrolled Resource Consumption 취약점(CVE-2026-68763) [6][16]
- Apache Tomcat에서 발생하는 Improper Authorization 취약점(CVE-2026-66422) [7][17]
- Apache Tomcat에서 발생하는 Improper Input Validation 취약점(CVE-2026-65637) [8][18]
- Apache Tomcat에서 발생하는 Off-by-one Error 취약점(CVE-2026-65927) [9][19]
- Apache Tomcat에서 발생하는 Authentication Bypass by Capture-replay 취약점(CVE-2026-65905) [10][20]
