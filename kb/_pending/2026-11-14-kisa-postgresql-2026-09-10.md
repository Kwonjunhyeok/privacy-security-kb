# PostgreSQL 제품 보안 업데이트 권고 (PostgreSQL, CVE 6건, 2026-09-10)

- 게시: KISA 보호나라 보안공지 「PostgreSQL 제품 보안 업데이트 권고」, 2026-09-10 (nttId=72184)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- PostgreSQL 재단은 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[6]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- PostgreSQL에서 발생하는 Integer Overflow or Wraparound 취약점(CVE-2026-6473) [1][7]
- PostgreSQL에서 발생하는 UNIX Symbolic Link (Symlink) Following 취약점(CVE-2026-6475) [2][8]
- PostgreSQL에서 발생하는 Use of Inherently Dangerous Function 취약점(CVE-2026-6477) [3][9]
- PostgreSQL에서 발생하는 Uncontrolled Recursion 취약점(CVE-2026-6479) [4][10]
- PostgreSQL에서 발생하는 Stack-based Buffer Overflow 취약점(CVE-2026-6637) [5][11]
- PostgreSQL에서 발생하는 SQL Injection 취약점(CVE-2026-6476) [6][12]
