# WordPress weDevs Project Manager 플러그인 보안 업데이트 권고 (CVE-2026-116512, 2026-11-02)

- 게시: KISA 보호나라 보안공지 「WordPress 제품 보안 업데이트 권고」, 2026-11-02 (nttId=72262)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- WordPress의 weDevs Project Manager 플러그인 취약점을 해결한 보안 업데이트 발표 [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- weDevs Project Manager에서 발생하는 Unrestricted Upload of File with Dangerous Type 취약점(CVE-2026-116512) [1][2]

## 영향을 받는 제품 및 해결 방안

|---|---|---|---|
| CVE-2026-116512 | weDevs Project Manager | 4.1.2 미만 | 4.1.2 이상 |
