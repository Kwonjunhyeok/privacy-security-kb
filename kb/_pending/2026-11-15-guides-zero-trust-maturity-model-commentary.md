# 제로트러스트 성숙도 모델 해설서

## 게시 정보

- KISA 게시판 제목: 제로트러스트 성숙도 모델 해설서 (가이드라인 58번, 등록일 2025-12-18). 담당부서 칸은 게시물에 보이지 않음(확인필요).
- 게시물 본문: 「제로트러스트 가이드라인 2.0」의 성숙도 수준 평가 체크리스트를 실무에 활용하는 모든 분에게 도움을 주려고 제작했다고 적음.
- 표지 제목: "보안 실무자를 위한 제로트러스트 성숙도 모델 해설서", 과학기술정보통신부·한국인터넷진흥원 로고.
- 첨부 182쪽. 글자 추출이 불완전해 표지·목차(2~4쪽)·6·25쪽을 렌더링해 읽었다.

## 목적·적용 대상

- 목적(원문 6쪽 1.1): 제로트러스트 가이드라인 2.0 의 성숙도 수준 평가 체크리스트에 대한 이해 제공. 항목 문구·용어의 정의와 해석, 항목이 아키텍처에서 갖는 의미, 구현 기반 기술, 성숙도 수준을 증명할 증적 자료를 제시. 6대 핵심 요소와 교차 기능의 세부역량·문항별 분석 방안을 제시해 조직이 구현 현황을 평가하게 한다고 적음.
- 대상: 체크리스트를 실무에 활용하는 보안 실무자(표지·게시물).

## 목차

- 제1장 제로트러스트 성숙도 모델 해설서 개요: 1. 성숙도 모델 해설서의 목적 및 구성(1.1 목적, 1.2 구성) / 2. 성숙도 수준 평가 절차 및 도입 절차(2.1 성숙도 수준 평가 절차, 2.2 성숙도 수준 평가 기반 도입 절차)
- 제2장 제로트러스트 성숙도 모델: 1. 성숙도 모델 소개 / 2. 성숙도 모델 구조(2.1 핵심 요소, 2.2 기능 및 세부역량, 2.3 역량별 성숙도 수준 체크리스트) / 3. 성숙도 수준 평가 요소(3.1 국내 환경을 반영한 성숙도 평가 요소 구성, 3.2 핵심 요소 및 교차 기능 체계) / 4. 성숙도 수준 정의(4.1 4단계 성숙도 수준 정의, 4.2 핵심 요소별, 4.3 핵심 요소별 기능별: 식별자·신원, 기기 및 엔드포인트, 네트워크, 시스템, 애플리케이션 및 워크로드, 데이터)
- 제3장 성숙도 수준 평가를 위한 체크리스트 해설(42~): 1. 식별자·신원(식별자 관리, 인증, 위험도 평가, 접근 관리) / 2. 기기 및 엔드포인트(정책 준수 모니터링, 데이터 접근제어, 자산관리, 기기 위협 보호) / 3. 네트워크(네트워크 세분화, 위협 대응, 트래픽 암호화, 트래픽 관리, 네트워크 회복성) / 4. 시스템(접근통제, 시스템 계정 관리, 네트워크 분리 정책, 시스템 보안 및 정책 관리) / 5. 애플리케이션 및 워크로드(애플리케이션 접근, 위협 보호, 접근 가능한 애플리케이션, 안전한 애플리케이션 배포, 소프트웨어·애플리케이션 보안) / 6. 데이터(목록 관리, 접근 결정방법, 암호화, 분류, 손실 방지) / 7. 가시성 및 분석(134~) / 8. 자동화 및 통합(147~)
- 부록: 1. 핵심 요소별 기술 및 주요 솔루션 예시(162) / 2. 핵심 요소별 증적 자료 예시(166) / 3. 용어 정의(175) / 4. 약어 정의(177)

## 장별 요지

- 4단계 성숙도 수준(원문 25쪽 표 4): 1 기존(정적, 경계기반, 수동) / 2 초기(일부 자동화) / 3 향상(자동화, 중앙 집중적, 통합) / 4 최적화(동적, 완전 자동화). 원문은 가이드라인 1.0 이 기존·향상·최적화 3단계였고 2.0 에서 CISA·NSA 최신 모델을 반영해 '초기'를 더한 4단계로 재정의했다고 적음.
- 실무 활용: 항목별 해설은 제3장 해당 절을, 증적 준비는 부록 2를 본다(목차 기준). 제3장 각 항목의 해설 내용은 원문 미확인 → 확인필요.
- 성숙도 평가 절차·도입 절차(제1장 2절)는 원문 미확인 → 확인필요.

## 근거 법령

- 읽은 쪽에서 법령 조문 인용은 보지 못했다(확인필요). 성숙도 평가와 체크리스트는 안내서 권고다.
