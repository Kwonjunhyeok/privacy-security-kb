# SonicWall 제품 보안 업데이트 권고 (SMA1000 Series (6210, 7210, 8200v), CVE 3건, 2026-10-13)

- 게시: KISA 보호나라 보안공지 「SonicWall 제품 보안 업데이트 권고」, 2026-10-13 (nttId=72213)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- SonicWall社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- SonicWall SMA1000에서 발생하는 Server-Side Request Forgery (SSRF) 취약점(CVE-2026-102255) [1][2]
- SonicWall SMA1000에서 발생하는 OS Command Injection 취약점(CVE-2026-102256) [1][3]
- SonicWall SMA1000에서 발생하는 Path Traversal 취약점(CVE-2026-102257) [1][4]
