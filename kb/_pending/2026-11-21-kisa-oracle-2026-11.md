# Oracle 제품 보안 업데이트 권고 (2026년 11월, 11-18·11-19 공지 병합)

- KISA 보호나라 보안공지 「Oracle 제품 보안 업데이트 권고」 2건을 UPDATE.md 규칙(같은 제조사는 한 문서로 묶음)에 따라 하나로 병합함.
  - 공지 1: 2026-11-18 게시 (nttId=72313) — Oracle Java SE·JavaFX·GraalVM 계열
  - 공지 2: 2026-11-19 게시 (nttId=72315) — Oracle WebLogic Server·Application Object Library·Concurrent Processing·PeopleSoft Enterprise PeopleTools·VM VirtualBox 계열
- 아래 표·값은 각 공지 본문을 그대로 옮긴 것이며, 원문을 다시 열어 재확인하지 않고 기존 초안 내용을 합침.

## 개요

- Oracle社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 (양 공지 공통) [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 공지 1 (2026-11-18, nttId=72313) — Java SE·JavaFX·GraalVM 계열

### 설명

- Oracle Java SE, Oracle JavaFX의 libxml2에서 발생하는 XML 외부 엔티티(XXE) 주입 및 SSRF 취약점(CVE-2026-86144)
- Oracle Java SE의 Compiler에서 발생하는 Heap-based Buffer Overflow 취약점(CVE-2026-114938)
- Oracle Java SE의 JGSS에서 발생하는 정보 노출 및 데이터 변조 취약점(CVE-2026-114939)
- Oracle Java SE의 JSSE에서 발생하는 정보 노출 및 데이터 변조 취약점(CVE-2026-114940)
- Oracle Java SE의 Compiler에서 발생하는 서비스 거부 및 데이터 변조 취약점(CVE-2026-114941)
- Oracle Java SE의 Libraries에서 발생하는 서비스 거부 및 데이터 변조 취약점(CVE-2026-114942)
