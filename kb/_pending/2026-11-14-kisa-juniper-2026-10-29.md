# Juniper Networks 제품 보안 업데이트 권고 (Session Smart Router·Session Smart Conductor, CVE 10건, 2026-10-29)

- 게시: KISA 보호나라 보안공지 「Juniper Networks 제품 보안 업데이트 권고」, 2026-10-29 (nttId=72249)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- Juniper Networks社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Juniper Session Smart Router, Session Smart Conductor에서 발생하는 Link Following 취약점(CVE-2026-103401) [1][2]
- Juniper Session Smart Router, Session Smart Conductor에서 발생하는 Insufficient Verification of Data Authenticity 취약점(CVE-2026-103402) [1][3]
- Juniper Session Smart Router, Session Smart Conductor에서 발생하는 OS Command Injection 취약점(CVE-2026-103403) [1][4]
- Juniper Session Smart Conductor에서 발생하는 OS Command Injection 취약점(CVE-2026-103406) [1][5]
- Juniper Session Smart Router, Session Smart Conductor에서 발생하는 Path Traversal 취약점(CVE-2026-103407) [1][6]
- Juniper Session Smart Router에서 발생하는 Stack-based Buffer Overflow 취약점(CVE-2026-103408) [1][7]
- Juniper Session Smart Router에서 발생하는 Missing Authentication for Critical Function 취약점(CVE-2026-103409) [1][8]
- Juniper Session Smart Router에서 발생하는 Integer Overflow or Wraparound 취약점(CVE-2026-103410) [1][9]
- Juniper Session Smart Router에서 발생하는 Integer Underflow 취약점(CVE-2026-103411) [1][10]
- Juniper Session Smart Router, Session Smart Conductor에서 발생하는 OS Command Injection 취약점(CVE-2026-106079) [1][11]
