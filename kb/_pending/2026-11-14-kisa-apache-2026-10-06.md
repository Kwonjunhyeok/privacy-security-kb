# Apache 제품 보안 업데이트 권고 (Apache HTTP Server, CVE 16건, 2026-10-06)

- 게시: KISA 보호나라 보안공지 「Apache 제품 보안 업데이트 권고」, 2026-10-06 (nttId=72208)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- Apache 재단은 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Apache HTTP Server에서 발생하는 NULL Pointer Dereference 취약점(CVE-2026-46729) [1][2]
- Apache HTTP Server에서 발생하는 Exposure of Sensitive Information to an Unauthorized Actor 취약점(CVE-2026-47360) [1][3]
- Apache HTTP Server에서 발생하는 Missing Authentication for Critical Function 취약점(CVE-2026-48005) [1][4]
- Apache HTTP Server에서 발생하는 Out-of-bounds Write 취약점(CVE-2026-56153) [1][5]
- Apache HTTP Server에서 발생하는 Use After Free 취약점(CVE-2026-56154) [1][6]
- Apache HTTP Server에서 발생하는 Out-of-bounds Write 취약점(CVE-2026-56449) [1][7]
- Apache HTTP Server에서 발생하는 Use After Free 취약점(CVE-2026-57941) [1][8]
- Apache HTTP Server에서 발생하는 Out-of-bounds Write 취약점(CVE-2026-59685) [1][9]
- Apache HTTP Server에서 발생하는 Improper Privilege Management 취약점(CVE-2026-59797) [1][10]
- Apache HTTP Server에서 발생하는 Improper Access Control 취약점(CVE-2026-63045) [1][11]
- Apache HTTP Server에서 발생하는 Stack-based Buffer Overflow 취약점(CVE-2026-63292) [1][12]
- Apache HTTP Server에서 발생하는 NULL Pointer Dereference 취약점(CVE-2026-63686) [1][13]
- Apache HTTP Server에서 발생하는 HTTP Request/Response Smuggling 취약점(CVE-2026-63718) [1][14]
- Apache HTTP Server에서 발생하는 Authentication Bypass by Capture-replay 취약점(CVE-2026-73636) [1][15]
- Apache HTTP Server에서 발생하는 Use After Free 취약점(CVE-2026-73637) [1][16]
- Apache HTTP Server에서 발생하는 Integer Overflow or Wraparound 취약점(CVE-2026-93546) [1][17]
