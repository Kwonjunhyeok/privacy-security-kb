# Check Point 제품 보안 업데이트 권고 (Security Management Server·Multi-Domain Security Management Server 등, CVE 6건, 2026-09-18)

- 게시: KISA 보호나라 보안공지 「Check Point 제품 보안 업데이트 권고」, 2026-09-18 (nttId=72192)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- Check Point社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[6]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Security Management Server, Multi-Domain Security Management Server, Log Server, Multi-Domain Log Server에서 발생하는 Stack-based Buffer Overflow 취약점(CVE-2026-91843) [1][7]
- Security Management Server, Multi-Domain Security Management Server에서 발생하는 Improper Authentication 취약점(CVE-2026-16232) [2][8]
- Security Management Server, Multi-Domain Security Management Server에서 발생하는 Improper Authentication 취약점(CVE-2026-62144) [3][9]
- Security Management Server, Multi-Domain Security Management Server에서 발생하는 Authentication Bypass Using Alternate Path or Channel 취약점(CVE-2026-18574) [4][10]
- Security Gateway, Security Management Server, Spark Firewall에서 발생하는 Heap-based Buffer Overflow 취약점(CVE-2026-85103) [5][11]
- Security Gateway, Spark Firewall에서 발생하는 Improper Certificate Validation 취약점(CVE-2026-85102) [6][12]
