# F5 제품 보안 업데이트 권고 (NGINX Plus·NGINX Open Source, CVE 5건, 2026-10-20)

- 게시: KISA 보호나라 보안공지 「F5 제품 보안 업데이트 권고」, 2026-10-20 (nttId=72224)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- F5社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[5]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- NGINX Plus, NGINX Open Source에서 발생하는 Heap-based Buffer Overflow 취약점(CVE-2026-15176) [1][6]
- NGINX Plus, NGINX Open Source에서 발생하는 Heap-based Buffer Overflow 취약점(CVE-2026-93479) [2][7]
- NGINX Plus, NGINX Open Source에서 발생하는 Use After Free 취약점(CVE-2026-97205) [3][8]
- NGINX Plus, NGINX Open Source에서 발생하는 Encoding Error 취약점(CVE-2026-95101) [4][9]
- NGINX Plus, NGINX Open Source에서 발생하는 Use of Uninitialized Resource 취약점(CVE-2026-97629) [5][10]
