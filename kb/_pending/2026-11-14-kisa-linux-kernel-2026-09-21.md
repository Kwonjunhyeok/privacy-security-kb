# Linux 제품 보안 업데이트 권고 (Linux Kernel, CVE 3건, 2026-09-21)

- 게시: KISA 보호나라 보안공지 「Linux 제품 보안 업데이트 권고」, 2026-09-21 (nttId=72195)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- 리눅스 재단은 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[3]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Linux 커널에서 발생하는 Improper Check for Unusual or Exceptional Conditions 취약점(CVE-2025-39682) [1][4]
- Linux 커널에서 발생하는 Race Condition 취약점(CVE-2025-39964) [2][5]
- Linux 커널에서 발생하는 Out-of-bounds Write 취약점(CVE-2026-53266) [3][6]
