# Fortinet 제품 보안 업데이트 권고 (FortiWeb·FortiClientWindows 등, CVE 3건, 2026-08-20)

- 게시: KISA 보호나라 보안공지 「Fortinet 제품 보안 업데이트 권고」, 2026-08-20 (nttId=72163)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- Fortinet社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]~[3]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- FortiWeb에서 발생하는 Improper Authentication 취약점(CVE-2026-26035) [1][4]
- FortiClientWindows에서 발생하는 Classic Buffer Overflow 취약점(CVE-2026-70465) [2][5]
- FortiManager, FortiManager Cloud에서 발생하는 Authentication Bypass Using an Alternate Path or Channel 취약점(CVE-2026-70468) [3][6]
