## 목적·적용 대상

- 발간 목적(원문 6쪽 요지): 알려진 LLM 보안 위협을 체계적으로 분류하고 위협별 분석 방법과 완화 방안을 제시. 학습부터 운영까지 LLM 시스템 생명 주기 전반의 위협을 분석하고 진단·대응 방안 제시. 원문은 「인공지능(AI) 보안 안내서」의 후속으로, LLM 시스템에 특유한 위협(탈옥, 간접 프롬프트 인젝션, 에이전트 도구 오용, 모델 공급망 손상 등)을 진단·대응 차원에서 다룬다고 적음.
- 대상(원문 6·9쪽): LLM 과 LLM 애플리케이션, 운영 환경·도구·외부 데이터·사용자 경계까지의 LLM 시스템 전반. 독자는 CEO·CISO·CSO, 보안 실무자, AI·ML 개발자, IT 운영자, 산업 도메인 전문가 등이며 장별 권장 독자와 기술 난이도 표(9쪽)가 있음.
- 적용 범위(원문 10쪽): 안전(Safety)과 보안(Security)을 함께 포괄하고 통합적 위험 관리 관점에서 접근.

## 장별 요지

- 실무자는 위협 분류를 제2장, 업종별 시나리오를 제3장(자기 산업 절), 위협별 대응 방안을 제4장과 별첨2에서 찾는다(목차 기준).
- 위협 분류 체계: 같은 발행처의 「AI 보안 레드티밍 가이드」(2026.7) 표 3이 이 매뉴얼을 분류 기준으로 인용하며 D(데이터)·M(모델)·A(에이전트)·S(공급망) 코드를 쓴다. 이 매뉴얼의 실제 위협 항목 코드·개수와 "고성능 모델 위협" 항목은 원문 미확인 → 확인필요.
- 제2~4장 본문 내용은 이번에 렌더링하지 않아 원문 미확인 → 확인필요.

## 근거 법령

- 원문 6쪽은 배경 설명으로 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 발효와 고영향 AI 에 대한 사람의 관리·감독 의무, 「범용 인공지능 행동강령(General-Purpose AI Code of Practice)」을 언급한다. 조문 번호 인용은 읽은 범위에서 보지 못했다(확인필요).
- 매뉴얼의 진단·대응 방안은 안내서 권고다.
