# 안전조치 의무 위반 3개 사업자 제재

- 보도자료: 「개인정보위, 안전조치 의무 위반 3개 사업자 제재」 (작성일 2026-07-08, 조사2과. 첨부 파일명은 "260709 10시보도" — 게시일과 보도시점 불일치, 확인필요)
- 의결: 2026년 7월 8일(수) 제13회 전체회의 (페이지 요약 기준)
- 위반 조항: 조문 번호 미표기 → 확인필요

## 사실관계 요지

- 락앤락: 2024년 4월 메일서버 취약점 악용, 2024.5.29.~5.30. 회원 DB 유출, 2024.11.22.~11.26. 재침투로 파일서버 업무자료 유출. 고객 약 130만 건, 임직원 관련 1,111건(신분증·운전면허·통장 사본). 협박 메일로 인지. 2022년 취약점 미패치, 주요 서버 관리자 계정 동일 비밀번호, 고유식별정보 비암호화, 폐점 매장 등 49,466건 미파기.
- 유베이스: 2024년 4월 홈페이지 관리자 계정 악용, 문의게시판 이용자 1,852명 이름·전화번호·이메일·회사명 유출, 텔레그램 게시. 관리자 페이지 IP 제한 없음, ID/PW만 사용, 접속기록 관리 미흡.
- 썬포토: 2024년 8월 관리자 계정 악용, 회원 약 17만 명 정보와 주문 13건 유출, 구매자 1명 대상 보이스피싱 시도. 관리자 페이지 IP 제한 없음, 접속기록 미보관.

## 연관 후보

- 개인정보 보호법 제21조(파기), 제24조(고유식별정보), 제29조
- ISMS-P 2.10.8 패치관리, 2.5.4 비밀번호 관리, 2.9.4 로그 관리, 3.4.1 개인정보의 파기
