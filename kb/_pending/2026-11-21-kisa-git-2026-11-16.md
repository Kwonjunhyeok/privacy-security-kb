# Git 제품 보안 업데이트 권고 (2026-11-16)

- 게시: KISA 보호나라 보안공지 「Git 제품 보안 업데이트 권고」, 2026-11-16 (nttId=72307)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.

## 개요

- Git 패키지에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1][2]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Git에서 발생하는 취약점(CVE-2026-111760) [1][2]
- Git에서 발생하는 Heap-based Buffer Overflow 취약점(CVE-2026-105437) [2][3]
