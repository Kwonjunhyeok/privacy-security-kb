# Langflow 제품 보안 업데이트 권고 (Langflow OSS, CVE 6건, 2026-08-31)

- 게시: KISA 보호나라 보안공지 「Langflow 제품 보안 업데이트 권고」, 2026-08-31 (nttId=72174)
- 아래 표·값은 공지 본문 그대로 옮김. 제조사 원 권고 링크는 '참고사이트' 참조.


## 개요

- IBM社는 자사 제품에서 발생하는 취약점을 해결한 보안 업데이트 발표 [1]
- 영향을 받는 버전을 사용 중인 사용자는 해결 방안에 따라 최신 버전으로 업데이트 권고

## 설명

- Langflow OSS에서 발생하는 Missing Authentication for Critical Function 취약점(CVE-2026-8446) [1][2]
- Langflow OSS에서 발생하는 Reliance on Untrusted Inputs in a Security Decision 취약점(CVE-2026-9077) [1][3]
- Langflow OSS에서 발생하는 OS Command Injection 취약점(CVE-2026-17623) [1][4]
- Langflow OSS에서 발생하는 OS Command Injection 취약점(CVE-2026-17625) [1][5]
- Langflow OSS에서 발생하는 Incorrect Privilege Assignment 취약점(CVE-2026-17626) [1][6]
- Langflow OSS에서 발생하는 Incomplete List of Disallowed Inputs 취약점(CVE-2026-17630) [1][7]
