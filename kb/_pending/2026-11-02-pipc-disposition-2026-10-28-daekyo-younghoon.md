# ㈜대교·영훈의료재단 안전조치 의무 위반 제재

- 보도자료: 「개인정보위, 안전조치 의무 위반 2개 사업자에 38억 8,500만 원 과징금 부과」 (작성일 2026-10-29)
- 의결: 2026-10-28 제21회 전체회의. 보도자료 본문은 "10월 28일(목)"으로 적었으나 2026-10-28은 수요일이고 같은 날 보도자료(nttId=12601)도 "(수)" — 원문 요일 오기로 보고 요일은 적지 않음. 연도는 본문 미표기(작성일 2026-10-29 기준).
- 작성부서: 게시판 "조사2과", 첨부파일명 "(조사1 2과)" — 표기 불일치
- 위반 조항: 본문은 "「개인정보 보호법」에 따른 안전조치 의무" 위반이라고만 적고 조문 번호 미표기 → 확인필요 (의결서 확인 필요)
- 의결서 원문 URL: 확인필요

## 사실관계 요지

- ㈜대교: 해커가 관계사 홈페이지 웹 취약점으로 웹셸 업로드, 2024년 8월·2025년 2월 두 차례 악성코드 실행. 관계사 웹서버와 연동된 회원 DB에서 약 65만 명의 이름·생년월일·휴대전화번호·연계정보(CI) 등 유출.
  - 원인: 관계사 웹서버→회원 DB 직접 접근 허용, 2024년 8월 보안관제업체 이상행위 안내 후 분석·차단 소홀, CPO의 내부 관리계획 이행 점검 소홀.
- 영훈의료재단: 2024년 3월 병원 홈페이지 SQL 인젝션 공격으로 회원 188,481명의 아이디·비밀번호·이름·휴대전화번호·생년월일 유출.
  - 원인: 웹방화벽 미설치·미운영, 웹 취약점 점검·입력값 검증 미실시, 안전하지 않은 암호 알고리즘 사용 및 솔트 미사용(일부 비밀번호 복호화 가능).

## 연관 후보

- 개인정보 보호법 제29조(안전조치의무), 개인정보의 안전성 확보조치 기준(접근통제, 암호화)
- ISMS-P 2.6.1 네트워크 접근, 2.7.1 암호정책 적용, 2.10.x(웹 취약점 관련), 2.11.x 사고 대응, 1.1.2 최고책임자의 지정
